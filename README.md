# 🎯 Oferta Reta Final ENEM 2026 — Página de Vendas

Página de vendas oficial de alta conversão para o produto **"Kit Reta Final ENEM 2026 (200 Mapas Mentais em PDF)"**, com identidade visual premium Crimson Red, mockups 3D, prova social, tabela de planos (Básico R$ 9,90 e Completo R$ 19,90), pop-up de upgrade estratégico (R$ 16,90) e rastreamento pronto via UTMify/Meta Ads.

---

## ⚡ Como Visualizar Localmente (1 Clique)
- Dê dois cliques em:
  👉 **`ABRIR_OFERTA.bat`**
- A página abrirá diretamente no seu navegador padrão.

---

## ⚙️ Configurações Centrais (`config.js`)
Todas as configurações de checkout, preços e rastreamento ficam centralizadas no arquivo [`config.js`](./config.js):
- **Links de Checkout:** URLs da plataforma GG Checkout (Básico, Completo e Upgrade).
- **Parâmetros UTM:** Repasse automático de parâmetros de tráfego pago (`utm_source`, `utm_campaign`, etc.).
- **Datas Oficiais ENEM:** Contagem regressiva e datas do 1º e 2º dia.

## 🚀 Como Fazer Deploy na Vercel
1. Instale ou use o Vercel CLI:
   ```bash
   vercel
   ```
2. Ou conecte seu repositório no dashboard da Vercel apontando o **Root Directory** para:
   ```text
   5_DEPLOY_OFERTA_ENEM
   ```
3. Pronto! Não necessita comando de build nem framework preset (`Other`).
